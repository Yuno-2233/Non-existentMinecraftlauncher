# Non-existent Minecraft Launcher

一个正在完善的可扩展 Minecraft 启动器。

---

## 如何使用

### 下载
请访问 [GitHub Releases 页面](https://github.com/Yuno-2233/Non-existentMinecraftlauncher/releases) 下载最新版本的 `.jar` 文件和配套的启动脚本。

### 运行
在运行启动器之前，请确保您的电脑已经安装了 **Java** 运行环境。
双击 `start.bat` (Windows) 或 `start.sh` (Linux/Mac) 即可启动。
