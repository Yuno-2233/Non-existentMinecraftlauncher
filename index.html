Non-existentMinecraftLauncher Engine

一个极轻量、模块化的 CLI Minecraft 启动器引擎，专为零启动延迟与高度可扩展的 Mod 系统设计。所有功能均由 Mod 提供，引擎本身仅负责 Mod 的发现、依赖解析与隔离加载。

下载最新版 快速开始

核心特性

Mod 架构

所有功能均由 Mod 提供，引擎本身仅负责发现、依赖解析与隔离加载。内置 core、versions、account、installer 等基础 Mod，可随意扩展。

零感知启动

精调 JVM 参数，确保引擎本身瞬间响应。启动游戏时自动选择最优 Java 运行时，支持版本隔离与自定义参数。

全面兼容

支持原版、Forge、Fabric、NeoForge 等加载器，自动解析版本 JSON，处理原生库与资源文件下载。

账号系统

支持离线登录、微软正版登录（OAuth 设备代码流程）以及第三方 Authlib-Injector 验证，多角色管理。

跨平台

纯 Java 实现，可在 Windows、Linux、macOS 等任何支持 Java 11+ 的系统上运行。

自动化构建

GitHub Actions 自动构建发布，每次推送标签即生成可执行 JAR 文件。

快速使用

确保已安装 Java 11+ 并将 neml.jar 放置于合适位置，然后执行：

# 查看所有可用命令（包括内置 Mod 提供的命令）
java -jar neml.jar core help

# 添加并切换到你的 .minecraft 目录
java -jar neml.jar versions dir add /path/to/.minecraft

# 安装原版 1.21 版本
java -jar neml.jar installer install 1.21

# 添加一个离线账号（或使用 account login 登录微软账号）
java -jar neml.jar account add Steve

# 启动游戏！
java -jar neml.jar launcher launch 1.21

更多详细文档请访问 文档页面 或 GitHub 仓库。

开发 Mod

引擎支持外部 Mod（放置于 ./neml/mod/）与内置 Mod（源码放在 src/main/builtin-mods/）。每个 Mod 需要提供 neml-mod.json 描述文件。

详细开发指南请参考仓库中的 源代码 和内置 Mod 示例。
