下载 NEML

最新版本可从 GitHub Releases 获取，或通过 Actions 下载开发构建。

下载最新 Release (neml.jar)

命令行下载

wget https://github.com/Yuno-2233/Non-existentMinecraftlauncher/releases/latest/download/neml.jar

或者使用 curl：

curl -L -o neml.jar https://github.com/Yuno-2233/Non-existentMinecraftlauncher/releases/latest/download/neml.jar

系统要求

需要 Java 11 或更高版本。推荐使用 OpenJDK 17+。

启动器本身可在任何操作系统上运行，但 Minecraft 游戏可能需要特定平台的原生库（x86_64 架构）。
