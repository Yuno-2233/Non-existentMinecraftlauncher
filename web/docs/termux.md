# 关于纯终端开发
推荐使用noevim开发

---

## 🧭 一、Neovim 基础模式（必须掌握）

| 模式 | 进入方式 | 作用 | 退出方式 |
| :--- | :--- | :--- | :--- |
| **普通模式** | 按 `ESC` | 执行快捷键、移动光标 | - |
| **插入模式** | 按 `i` | 输入文字（编辑） | 按 `ESC` |
| **可视模式** | 按 `v`（字符）或 `V`（行） | 选中文本 | 按 `ESC` |
| **命令模式** | 按 `:` | 执行命令（如保存、退出） | 按 `Enter` 执行 |

> **手机 Termux 提示**：屏幕键盘顶部有 `ESC`、`CTRL`、`ALT` 等键，部分组合键需同时按住。

## 📂 二、文件管理

### 1. `nvim-tree.lua`（文件树）
- **打开/关闭**：按 `;` + `e`（Toggle）
- **在树内导航**：`j` 下移，`k` 上移，`Enter` 打开文件/目录
- **返回上级**：按 `-` 键
- **刷新**：按 `R`
- **新建文件**：按 `a` 然后输入文件名
- **新建目录**：按 `d` 然后输入目录名
- **删除**：按 `d`（需要确认）
- **重命名**：按 `r`
- **关闭树窗口**：在树内按 `q`

### 2. `telescope.nvim`（模糊查找器）
- `;` + `ff`：按文件名查找项目文件
- `;` + `fg`：在项目内全文搜索（类似 grep）
- `;` + `fb`：列出已打开的文件缓冲区（切换最近文件）
- 在 Telescope 窗口内：
  - `Ctrl+j` / `Ctrl+k` 上下移动
  - `Enter` 选择
  - `ESC` 取消

## ✍️ 三、代码编辑辅助

### 3. `nvim-autopairs`（自动补全括号）
- **用法**：直接输入 `(`、`[`、`{`、`"`、`'` 等，自动补全对应的闭合符号。
- **无需配置**，安装即用。

### 4. `Comment.nvim`（快速注释）
- **普通模式**：
  - `gcc`：注释/取消注释当前行
  - `gc` + 移动键（如 `gcj` 注释当前行和下一行）
- **可视模式**：选中多行后按 `gc` 注释/取消注释。

### 5. `flash.nvim`（快速跳转）
- **触发**：按 `;` + `s`（因为你用 `s` 会进入插入模式，已改为 Leader+s）
- 按下后，屏幕上会显示标签（字母），按对应字母即可跳转到该位置。
- **反向跳转**：按 `S`（如果没有覆盖，则与 `s` 相反）。

## 🎨 四、界面美化

### 6. `bufferline.nvim`（顶部标签栏）
- 切换标签：
  - `;` + `n`：下一个标签
  - `;` + `p`：上一个标签
- 关闭当前标签：命令 `:bdelete` 或按 `;` + `q`（如果你设置了）。

### 7. `lualine.nvim`（状态栏）
- 无需操作，自动显示在底部，显示当前模式、文件名、Git 状态、行号等。

### 8. `dashboard-nvim`（启动页）
- 打开 Neovim 无文件时自动显示。
- 手动打开：`;` + `d`（快捷键）
- 在启动页上，按 `Enter` 打开最近文件，按 `e` 等操作（见界面提示）。

### 9. `indent-blankline.nvim`（缩进线）
- 安装即用，在 Python、YAML 等文件中自动显示缩进竖线，帮助看清层级。

## 🌳 五、语法高亮与代码折叠（`nvim-treesitter`）

- **高亮**：自动生效，比传统高亮更精确。
- **代码折叠**：
  - `zf`：在普通模式下选中一段代码后按 `zf` 创建折叠（需先可视模式选中）
  - `zo`：展开折叠
  - `zc`：关闭折叠
  - `zR`：展开所有折叠
  - `zM`：折叠所有
- 查看已安装语言：`:TSInstallInfo`
- 安装新语言：`:TSInstall <语言名>`（如 `:TSInstall rust`）

## 🔧 六、Git 集成（`gitsigns.nvim`）

- 在编辑区左侧显示 Git 增删改标记（`+`、`-`、`~`）。
- 跳转修改：
  - `]c`：跳转到下一个修改块
  - `[c`：跳转到上一个修改块
- 预览当前修改：`:Gitsigns preview_hunk`
- 撤销当前修改：`:Gitsigns reset_hunk`
- 查看 Blame：`:Gitsigns blame_line`

## 🎨 七、颜色主题切换

- 已安装：`dracula` 和 `onedark`
- 临时切换：`:colorscheme dracula` 或 `:colorscheme onedark`
- 永久设置：在 `init.vim` 中添加 `colorscheme dracula`（默认）。

## 🔌 八、智能补全（`coc.nvim`）

- **触发**：输入单词后自动弹出补全菜单。
- **导航**：
  - `<Tab>`：选择下一项
  - `<Shift+Tab>`：选择上一项
- **确认**：
  - `<Enter>`：确认当前选中（补全并填入）
  - `<Ctrl+y>`：备选确认键（如果 Enter 被其他插件干扰）
- **取消补全**：按 `ESC`
- **常见操作**：
  - `gd`（普通模式）：跳转到定义（由 coc 提供）
  - `gr`：查看引用
  - `rn`：重命名符号（在整个项目中）

## 🛠️ 九、常用命令与退出

| 操作 | 命令 |
| :--- | :--- |
| 保存文件 | `:w` |
| 退出 | `:q` |
| 保存并退出 | `:wq` |
| 强制退出（不保存） | `:q!` |
| 重新加载配置 | `:source %` 或重启 |
| 打开命令面板 | `:Telescope commands`（如果你装） |
| 查看帮助 | `:help <关键词>` |

## 📌 特别提醒（Termux 手机环境）

- **按键替代**：如果某些键（如 `<Tab>` 或 `<S-Tab>`）在屏幕键盘上难按，可以改用 `Ctrl+I`（相当于 Tab）、`Ctrl+Shift+I`（相当于 Shift-Tab）。
- **ESC**：Termux 顶部通常有 ESC 按钮，也可以按 `Ctrl+[` 代替。
- **长按屏幕**：可调出更多功能键（如 `CTRL`、`ALT`）。
- **粘贴**：在插入模式下，长按屏幕选择“粘贴”即可。
