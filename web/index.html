Non-existentMinecraftLauncher Engine

极轻量、模块化的 CLI Minecraft 启动器引擎，零启动延迟，高度可扩展的 Mod 系统。

下载最新版 快速开始

核心特性

Mod 架构

所有功能均由 Mod 提供，引擎本身仅负责发现、依赖解析与隔离加载。

零感知启动

精调 JVM 参数，引擎瞬间响应，自动选择最优 Java 运行时。

全面兼容

支持原版、Forge、Fabric、NeoForge，自动处理资源与原生库。

账号系统

离线、微软正版、第三方验证，多角色管理。

跨平台

纯 Java 实现，支持 Windows、Linux、macOS。

自动构建

GitHub Actions 自动构建发布，推送标签即生成 JAR。

快速使用

# 查看所有命令
java -jar neml.jar core help

# 添加 .minecraft 目录
java -jar neml.jar versions dir add /path/to/.minecraft

# 安装原版 1.21
java -jar neml.jar installer install 1.21

# 添加离线账号
java -jar neml.jar account add Steve

# 启动游戏
java -jar neml.jar launcher launch 1.21
