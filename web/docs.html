文档

欢迎阅读 NEML 使用文档。NEML 是模块化命令行 Minecraft 启动器引擎，通过 neml.jar 与子命令交互。所有功能均由 Mod 提供。

内置 Mod 命令

core

neml core list     列出已发现的 Mod
neml core reload   重新扫描 Mod 目录
neml core help [modid]  显示帮助（可过滤 mod）

versions

neml versions list                     列出当前 .minecraft 中的版本
neml versions dir add <路径>            添加 .minecraft 目录
neml versions dir list                 列出已添加目录
neml versions dir switch <索引>        切换工作目录
neml versions isolate <版本> [on|off]  管理版本隔离（默认开启）
neml versions config <版本> [set key value]  查看/设置版本配置

account

neml account list             列出所有账号
neml account add <用户名>     添加离线账号
neml account switch <索引/用户名>  切换账号
neml account login             登录微软账号（设备代码）
neml account logout            注销微软账号
neml account status            查看当前登录状态
neml account login3rd <服务器> <用户名> <密码>  添加第三方验证账号

installer

neml installer install <版本> [自定义名称]  安装 Minecraft 版本（自动下载 JSON、jar、库、资源）

java

neml java list              列出已添加的 Java 路径及版本
neml java dir add <路径>     添加 Java 目录
neml java dir list           列出已添加的目录
neml java dir switch <索引>  切换当前 Java
neml java info               显示当前 Java 详细信息

launcher

neml launcher set-default <版本>  设置默认启动版本
neml launcher launch [版本]       启动游戏（默认启动已设置的版本）

配置与数据目录

所有配置文件存放在工作目录下的 neml/ 文件夹中：

neml/
  config/
    versions/config.json   .minecraft 目录管理
    account/config.json    账号信息
    java/config.json       Java 运行时管理
    launcher/config.json   默认启动版本
  mod/                     外部 Mod（.jar）
  logs/                    运行日志
